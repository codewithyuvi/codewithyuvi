- Multi-tenant B2B SaaS with Postgres RLS via Prisma Extensions — eliminates cross-tenant data leaks at the ORM layer.

- BullMQ job queue offloading webhooks/audit logs off the event loop, cutting API response times from 10s to <5ms.
